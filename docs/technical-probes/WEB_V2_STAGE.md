状态：通过。

## 能力

- 从 `/api/v2/catalog` 动态生成类别、组件、表面、材料族和选项。
- 支持 SC01 draft、不可报价和价格待确认状态。
- 支持保存配置、revision 更新、分享链接加载和本地草稿。
